`@axe/surface/webmcp` offers a surface to the browser's own agent through WebMCP where the browser has it (feature-detected; experimental, draft API). `@axe/mcp` asks the user through MCP elicitation for a non-sensitive requirement (form mode) and offers the site's page for sensitive requirements and human steps (URL mode), with clients that declare the capability, and offers an experimental MCP Apps view for `display` results to hosts that negotiate the extension.
